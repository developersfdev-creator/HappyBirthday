BIRTHDAY SURPRISE WEBSITE

This version is pre-prepared. The birthday person does NOT need to enter a name, choose photos, choose a song, or type a message.

PHOTO FILES
Put your photos inside:
assets/photos/

Use these exact names:
photo1.jpg
photo2.jpg
photo3.jpg
photo4.jpg
photo5.jpg
photo6.jpg
photo7.jpg
photo8.jpg

You can use as many as you want (up to 8). If you only have 4 photos, just use photo1.jpg through photo4.jpg.

MUSIC FILE
Put your birthday song inside:
assets/music/birthday.mp3

The website will automatically load the photos and song when the recipient opens the surprise.

IMPORTANT
- Keep the file names exactly as shown.
- Use JPG photos for the simplest setup.
- Keep index.html, assets/photos, and assets/music together in the same folder structure.
- Open index.html in a browser to test it.
- Browsers may still require the recipient to tap the first button before sound can start; this is a browser autoplay restriction.
